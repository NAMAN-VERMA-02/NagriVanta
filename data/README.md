# Datasets

| File | What | Source / licence | Used for |
|---|---|---|---|
| `nyc311_sample.csv` | 5,000 real, recent NYC 311 service requests (street condition, street light, dirty condition, illegal dumping, missed collection, sewer, water) with coordinates | NYC Open Data — *311 Service Requests from 2020 to Present* (`erm2-nwe9`), public domain-style NYC Open Data terms | Classifier evaluation (`npm run eval` in `server/`) and the "real-world sample" analytics |
| `civic_labelled_india.json` | 120 **synthetic** Ghaziabad/Noida reports with human labels (category + priority), incl. Hindi and Hinglish text | Generated by `gen_labelled.js` (this repo) | Seeding the demo DB and evaluating AI/rule triage |

Re-download the NYC sample (no API key needed):

```bash
curl -G "https://data.cityofnewyork.us/resource/erm2-nwe9.csv" --data-urlencode "$select=unique_key,created_date,closed_date,agency,complaint_type,descriptor,borough,latitude,longitude,status" --data-urlencode "$where=complaint_type in('Street Condition','Street Light Condition','Sewer','Dirty Condition','Water System','Illegal Dumping','Missed Collection') AND latitude IS NOT NULL" --data-urlencode "$order=created_date DESC" --data-urlencode "$limit=5000" -o nyc311_sample.csv
```

## Larger datasets (not bundled — download manually if you want image AI later)

- **Urban Civic Issues Image Dataset: Potholes and Garbage (QR4Change, Pune)** — 4,937 labelled images, 5.67 GB, CC BY 4.0.
  https://data.mendeley.com/datasets/zndzygc3p3 (DOI 10.17632/zndzygc3p3.2) → "Download All".
- **Civic report dataset (Kaggle)** — short Indian civic complaint texts with categories.
  https://www.kaggle.com/datasets/sweetlinsara/civic-report-dataset — needs a free Kaggle account
  (Kaggle → Settings → API → *Create New Token* gives `kaggle.json`, then `kaggle datasets download -d sweetlinsara/civic-report-dataset`).
- **Road issues detection dataset (Hugging Face)** — https://huggingface.co/datasets/Programmer-RD-AI/road-issues-detection-dataset

The synthetic set is demo data only. Do not present it, or any accuracy measured on it, as real-world performance.
